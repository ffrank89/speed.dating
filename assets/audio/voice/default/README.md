# PLACEHOLDER letter sounds

These 26 sounds (`a.wav` … `z.wav`) are computer-generated stand-ins for the
girls' Animal Crossing-style voices. Replace them with real recordings.

**Quickest way:** put your recordings here with the same names (`a.wav` …
`z.wav`), replacing these. Godot picks them up by itself.

Full steps, naming rules and recording tips:
`docs/guides/replacing-placeholders.md` → "Her voice: the 26 letter sounds".
