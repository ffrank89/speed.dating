# 0006: Boss visibility: shown from the chapter's first day

- **Status:** Accepted
- **Date:** 2026-10-11
- **Affects:** [calendar.md](../design/calendar.md), [boss.md](../design/boss.md)

## Decision

Each chapter's boss is shown from day one, so dates can be planned around it.

## Why

Knowing the question up front turns the calendar into planning instead of guessing.

## Not chosen

Surprise boss revealed on the last day.

## Revisit when

Runs feel solved too early because the answer is always obvious.
