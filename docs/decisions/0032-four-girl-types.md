# 0032: Girls have one of 4 types, separate from tags

- **Status:** Accepted
- **Date:** 2026-10-13
- **Affects:** [boss.md](../design/boss.md), [girls.md](../design/girls.md)

## Decision

Each girl has one type out of 4: Brainy, Wild, Sweet, Artsy (placeholder names). Bosses are weak to some types and strong against others. Types are separate from synergy tags and from player attributes.

## Why

A type chart is easy to balance and reads like a personality.

## Not chosen

Tags double as types; the 4 player attributes as types; 6+ types.

## Revisit when

Players confuse types with tags, or 4 types don't give enough variety across bosses.
