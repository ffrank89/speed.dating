# 0010: Losing a boss ends the run

- **Status:** Accepted
- **Date:** 2026-10-11
- **Affects:** [boss.md](../design/boss.md), [core-loop.md](../design/core-loop.md)

## Decision

A boss loss ends the run.

## Why

Standard roguelike stakes; makes every day count.

## Not chosen

Retry the chapter; lose a girl instead.

## Revisit when

Losses feel too harsh with only one or two chapters.
