# 0023: No carry-over between runs in the first build

- **Status:** Accepted
- **Date:** 2026-10-11
- **Affects:** [core-loop.md](../design/core-loop.md)

## Decision

Nothing carries over in the first build. Unlocks (girls, perks, bosses) come later.

## Why

Prove the core run is fun before adding meta-progression.

## Not chosen

Unlocks from the start.

## Revisit when

The core run is fun and needs a reason to keep replaying.
