# 0013: Girl offers: 2–3 random profiles, some gated

- **Status:** Accepted
- **Date:** 2026-10-11
- **Affects:** [calendar.md](../design/calendar.md), [girls.md](../design/girls.md)

## Decision

Each date day offers 2–3 random profiles. Some girls appear only once the player reaches attribute or perk thresholds.

## Why

The roguelike draft: different girls each run, and training or perks change what's offered.

## Not chosen

Fixed cast every run; pick any girl freely.

## Revisit when

Offers feel too random to build toward a plan.
