# 0004: Run length: about 30 minutes

- **Status:** Accepted
- **Date:** 2026-10-11
- **Affects:** [core-loop.md](../design/core-loop.md)

## Decision

A full run is about 30 minutes; the first build is shorter. Replay comes from new combinations; unlocks come after the first build.

## Why

Short runs make losing cheap and "one more run" tempting.

## Not chosen

Hour-plus runs with saves mid-run.

## Revisit when

Playtest runs land far from 30 minutes.
