# 0007: Boss match-ups: types first, special rules later

- **Status:** Accepted
- **Date:** 2026-10-11
- **Affects:** [boss.md](../design/boss.md), [synergy.md](../design/synergy.md)

## Decision

Bosses have Pokémon-style type strengths and weaknesses now; a special rule per boss (like Balatro boss blinds) comes later.

## Why

Types are cheap to build and easy to read; special rules add variety once the base works.

## Not chosen

Special rules from the start; no match-ups at all.

## Revisit when

Types alone don't create enough variety between runs.
