# 0022: Items are flavor only in the first build

- **Status:** Accepted
- **Date:** 2026-10-11
- **Affects:** [player.md](../design/player.md), [dates.md](../design/dates.md)

## Decision

Items exist for reactions on dates but have no mechanical effect in the first build.

## Why

Keeps scope small; perks already carry the build mechanics.

## Not chosen

Items as a second perk-like system.

## Revisit when

Items feel pointless in playtests.
