# 0003: Run structure: chapters ending in life-event bosses

- **Status:** Accepted
- **Date:** 2026-10-11
- **Affects:** [core-loop.md](../design/core-loop.md), [boss.md](../design/boss.md), [calendar.md](../design/calendar.md)

## Decision

A run is several chapters in a fixed, escalating order, each a short stretch of days ending in a life-event boss (a concert or party, meeting the parents, Valentine's Day). The first build has one chapter.

## Why

Life events fit the dating theme and give natural difficulty steps.

## Not chosen

One long month with a single boss; abstract monster bosses.

## Revisit when

We add a second chapter, or one chapter feels too short to build a party.
