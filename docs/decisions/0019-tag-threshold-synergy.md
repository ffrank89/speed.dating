# 0019: Girl–girl synergy: shared tags at thresholds

- **Status:** Accepted
- **Date:** 2026-10-11
- **Affects:** [synergy.md](../design/synergy.md), [girls.md](../design/girls.md)

## Decision

Girls share tags that activate bonuses at thresholds (Teamfight Tactics traits), run by a dedicated tag-synergy system. No hand-written pairs or rivalries.

## Why

Scales to any number of girls with no extra writing, and makes profiles a draft.

## Not chosen

Hand-written pair bonuses and rivalries.

## Revisit when

Tags make girls feel interchangeable.
