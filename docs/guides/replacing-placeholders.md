# Replacing placeholders

Some art and sounds in the game are **stand-ins** until the real ones exist.
This page lists every one, where it's used, and how to swap in the real
thing. **No code needed.**

- **Placeholder art** is the **Godot logo** (`assets/placeholders/godot_logo.svg`).
  If you see the Godot logo in the game, that spot needs art.
- **Placeholder sounds** are free Kenney sounds (Interface Sounds, CC0),
  and her letter sounds, which were generated by a computer. They work, but
  they're meant to be replaced.
- **The music** is placeholder loops (below): where they came from and
  their licence aren't recorded yet, so they can't ship as they are.

## Two ways to replace something

### Way 1: swap the file, keep the name (easiest)

Best when the new file is the **same type** as the old one (`.wav` for `.wav`).

1. In Finder (or Explorer), open the project folder and find the placeholder,
   e.g. `assets/audio/ui/kenney_interface_sounds/confirmation_001.wav`.
2. Put your new sound there **with exactly the same name**, replacing the old one.
3. Switch back to Godot. It notices the change and re-imports by itself.

Nothing else to do: everything that used the old file now uses yours.

### Way 2: drag the new file into the slot

Best when the new file has a **different name or type** (e.g. `.ogg`), or
when you want to keep the placeholder around.

1. Drag your file into the project in Godot's **FileSystem** panel, e.g. into
   `assets/audio/ui/`.
2. Click the file that uses it (the **Plugged in at** column above), e.g.
   `data/option_styles/default.tres`.
3. In the Inspector, open the section (e.g. **Sounds**) and drag your file
   from FileSystem onto the slot (e.g. **Hit Sound**).
4. Press **F5** to play the game, or **F6** on a test bench (the date's is
   `scenes/Dates/FirstDate/FirstDateTest.tscn`) to hear or see it.

## Her voice: the 26 letter sounds

These work a little differently because the game finds them **by name** in a
folder, not through one slot each.

**To replace them all for every girl:** use Way 1. Put your 26 recordings in
`assets/audio/voice/default/` named `a.wav`, `b.wav` … `z.wav`, replacing the
placeholders.

**To give one girl her own letter sounds:**
1. Make a folder, e.g. `assets/audio/voice/smokey/`, and put her `a`…`z` files in it.
2. Click her girl file → **Dialogue → Voice → Letter Sounds Folder** → pick the new folder.

Things to know:
- Names must be the **lowercase letter**: `a.wav`, not `A.wav` or `a_sound.wav`.
- `.wav`, `.ogg` and `.mp3` all work. If a folder has both `a.wav` and
  `a.ogg`, the **`.wav` wins**, so delete the old placeholder when switching
  type.
- A missing letter is just silent, so you can replace them a few at a time.
- **Recording tips:** say each letter's name quickly ("ay", "bee", "see"…),
  keep each under **0.12 seconds**, cut any silence at the start, and record
  them all in one voice. Each girl's **Pitch** setting does the rest.

## Sound tips

| Sound | Good length | Tip |
|---|---|---|
| Letter sounds | under 0.12 s | No silence at the start, or her voice will lag behind the text |
| Hover | under 0.1 s | Quiet and soft: players hear it a lot |
| Roll tick | under 0.05 s | Plays up to 14 times per roll, so keep it tiny |
| Hit / miss | 0.2–0.6 s | Clearly happy / clearly disappointed |

- Volume for all option sounds is **Sounds → Volume Db** in the option style.
  The voice volume is **Volume Db** in each girl's Voice.
- **Keep track of where sounds come from.** If you use sounds you didn't make,
  check their licence allows use in a commercial game, keep the licence file
  next to them, and add a line to `CREDITS.md` at the top of the project.
  Kenney's packs are CC0 (free for any use) and a good first stop; the
  Interface Sounds pack already in the project came from
  [GitHub](https://github.com/Calinou/kenney-interface-sounds) (also on
  [OpenGameArt](https://opengameart.org/content/interface-sounds)).

## Art tips

- **Stat icons:** square pictures work best (the current Culture and
  Heart icons are 100 × 100). Each goes in its stat's file
  (`data/stats/`) → **Icon**. Size on the option bubbles is
  `data/option_styles/default.tres` → **Stat Icons → Icon Size**.
- When a placeholder is replaced, update the table at the top of this page,
  so it always shows what's left.
